# To‑Do Avanzato

Progetto tutorial per imparare JavaScript costruendo una semplice Single Page App.

## Avvio rapido
- `npm install` (opzionale per `express`/`vite` se vuoi usare i comandi npm)
- `npm run start` per avviare con http-server (installa `http-server` se necessario: `npm i -g http-server`)
- `npm run serve` per avviare il piccolo server Express (dopo `npm install`)

## File principali
- `index.html`, `styles.css` e `src/*.js`.

## Estensioni suggerite
- aggiungere drag-and-drop, date di scadenza, sincronizzazione con backend.

Buon apprendimento!
